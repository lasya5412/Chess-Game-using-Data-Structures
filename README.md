# Chess Game in C

## About the Project
This project is a beginner-friendly Chess Game developed using the C programming language as part of my Data Structures and Algorithms (DSA) learning journey.

The project represents a chessboard using a two-dimensional character array and allows players to move pieces by entering source and destination coordinates.

## Features
- 8 × 8 chessboard representation
- Initial arrangement of chess pieces
- Uppercase letters represent White pieces
- Lowercase letters represent Black pieces
- Empty squares represented by `.`
- User-input-based piece movement
- Basic coordinate validation
- Continuous gameplay until the user exits

## Technologies Used
- C Programming Language
- Two-Dimensional Arrays
- Loops and Conditional Statements
- Functions
- Standard Input/Output

## How to Run
1. Download or clone this repository.
2. Open `chess.c` in a C compiler or online C compiler such as OnlineGDB.
3. Compile and run the program.
4. Enter the source and destination coordinates when prompted.

## Current Limitations
This is an ongoing project. Currently, the program supports basic piece movement but does not yet validate all chess rules, alternate turns, or detect check and checkmate.
